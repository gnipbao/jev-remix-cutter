# 授权、上传、原创度和人脸

素材 own / licensed / unknown 与音乐许可分别声明。unknown 允许预览，正式渲染需明确确认。许可片单由用户导入；过期、格式不符、时长超限阻止正式渲染。原创度报告是作品组成的描述，不能证明合理使用、授权真实性或平台审核结果。

上传预览列出目标服务和要传的数据。score 只发需求和镜头文字；cards Provider 只发所选联系表。授权开关仅用于已获用户授权的本次运行；环境变量中凭据不能出现在请求预览、产物或命令参数。

同意登记册默认在 `~/.config/jev-remix/consents`，不在 Skill 或运行目录。用户本人在交互式终端执行 consent add，查看摘要并逐字确认。Agent 不代为执行，不编造授权书，不修改真实 registry.json。revoke 会让引用该身份的计划失效。

当前支持 keep、局部 blur 和 full-frame blur。当前人脸路径拒绝可能是可变帧率的素材；需要专门的时间戳后端。Haar 检测不能可靠找出所有脸，不能用于证明匿名化有效；检测框、漏检、遮挡和打码结果要视觉确认。严格隐私场景可显式指定 `faces plan --default blur --full-frame`，将入选来源区间整帧打码。

anonymize / swap 命令会校验可用证据并拒绝未就绪的后端。真实换脸需要 subject 和 target 各自有效的书面单独同意，匹配不确定按未知处理。未知年龄/色情检测结果不视为通过；可能未成年或色情内容、欺骗冒充禁用合成人脸。合成人脸未来启用必须强制显式和隐式标识，并验证标识存在；当前未实现规范完整的标识管线，因此不输出合成人脸。依据与后端许可见 [face-backends.md](../docs/face-backends.md)。
