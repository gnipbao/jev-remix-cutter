# 当前手法

实际执行能力以 docs/coverage.md 和 rendering.py 校验为准。不支持的字段会报错。

- 卡点：切点量化到节拍输出帧；低置信度必须审听，不假定算法判断强拍或 drop 正确。
- 变速：恒速或速度折线积分决定源时间，nearest/blend 为 CPU 档。RIFE、光流补帧未启用，不能把重复/混合帧称为 AI 补帧。
- 变换：局部缩放、位移和旋转键；保留主体，需要视觉检查裁切位置。
- 转场：硬切、闪白/闪黑、溶解和 wipeleft；闪烁密度受阈值限制。动作匹配与主体遮挡需专门模型，未自动执行。
- 声音：授权音乐或原创旁白、声明保留的原声、实际存在的音效文件，最终两遍 loudnorm；没有音效库时不生成假音效事件。
- 文字：显式时间区间的 ASS 字幕或已声明创作来源的文字图层；不推断歌词词级时间。
- 颜色：支持的基础预设；不声称实现 HDR 还原、LUT 授权库、Lab 全池匹配和高级局部颜色。
