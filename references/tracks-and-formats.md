# 包的选择

五个赛道包是可编辑的初始规则，不是学习得到的爆款模板。

| ID | 用途 |
| --- | --- |
| film-epic | 冲突钩子、推进、动作高潮、呼应 |
| emotional | 情绪与关系，较低镜头密度 |
| amv | 动漫素材随音乐推进 |
| car | 车辆运动、节拍切点 |
| ecommerce | 卖点钩子、产品证据、收束 |
| recut-trailer | 新主题和预告风弧线 |
| still-mad | 平缓缩放的镜头编排；当前素材导入仍以视频为主 |
| side-by-side | 契约保留，分屏渲染未启用，命令明确返回缺后端 |

包需与意图卡配合，不会自动实现 CP 叙事、歌词隐喻、跨作品蒙太奇或虚假剧情。具体规则在 packs 中，只加载与本任务有关的包。
